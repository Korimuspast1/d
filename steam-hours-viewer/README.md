# Steam Hours Viewer

Программа для Windows с графическим окном, которая показывает список игр вашего
Steam-профиля вместе с количеством наигранных часов — и позволяет **визуально**
(то есть только в интерфейсе самой программы, локально на вашем компьютере)
менять отображаемое число часов для любой игры.

> ⚠️ Это не "накрутка" и не взлом Steam. Реальную статистику в самом Steam/в
> профиле программа не трогает и не может изменить — это технически
> невозможно и не является целью проекта. Изменённые значения видны только
> внутри этого приложения (например, для скриншотов/стрима/личного удобства)
> и сохраняются локально в файле на вашем ПК.

## Возможности

- Загружает список игр и часы из вашего Steam-профиля (без необходимости
  вводить пароль — используется только публичная информация профиля).
- Показывает таблицу: название игры, часы, активность за 2 недели.
- Двойной клик (или кнопка «Изменить часы») — позволяет задать любое число
  часов для конкретной игры. Изменённые строки подсвечиваются и помечаются
  статусом «изменено».
- Кнопка «Сбросить к реальным» — возвращает подлинное значение из Steam.
- Поиск по названию игры, сортировка по колонкам.
- Работает офлайн на последних загруженных данных, если нет интернета.

## Как это работает технически

1. Вы указываете ссылку на свой Steam-профиль (например,
   `https://steamcommunity.com/id/ваш_ник`) или SteamID64.
2. Программа сначала пробует получить данные через **публичный** XML
   `steamcommunity.com/.../games?tab=all&xml=1` — он не требует ключа и
   виден в браузере даже без входа в аккаунт, если в настройках приватности
   профиля включено «Сведения об игре» → Открыто.
3. Если указан Steam Web API ключ — используется официальный и стабильный
   `IPlayerService/GetOwnedGames` API.

   ⚠️ **Важно:** устаревший публичный XML-эндпоинт Steam (шаг 2) сам по себе
   периодически нестабилен — иногда Steam вместо данных отдаёт обычную
   HTML-страницу сайта вместо XML. Это подтверждено проверкой напрямую на
   серверах Steam и **не связано с настройками приватности вашего профиля**.
   Если видите ошибку разбора XML / «Steam отдал HTML-страницу» — откройте
   «Настройки профиля» и укажите свой API-ключ
   (https://steamcommunity.com/dev/apikey, получается за 20 секунд через
   обычный вход в Steam) — с ключом данные грузятся надёжно всегда.

Пароль от Steam нигде не запрашивается и не нужен в любом из вариантов.

## Готовый .exe

Собирать ничего не нужно — файл уже скомпилирован (на настоящем Windows
через GitHub Actions) и лежит здесь:

```
steam-hours-viewer/release/SteamHoursViewer.exe
```

Просто скачайте/скопируйте его на Windows-компьютер и запустите двойным
кликом. Python не требуется.

При каждом изменении кода в этой папке GitHub Actions (`.github/workflows/build-exe.yml`)
автоматически пересобирает `SteamHoursViewer.exe` на `windows-latest`-раннере
и коммитит обновлённый файл обратно в эту же ветку — так что он всегда
актуален.

> Примечание: антивирус Windows может временно пометить файл как
> подозрительный — это известная особенность приложений, собранных
> PyInstaller (ложное срабатывание из-за упаковки Python в один файл).
> Если не доверяете — соберите .exe сами через `build.bat` (см. ниже) или
> запустите через `run.bat` напрямую из исходного кода.

## Быстрый старт (без сборки .exe)

1. Установите Python 3.10+ с [python.org](https://www.python.org/downloads/)
   (при установке отметьте галочку **Add Python to PATH**).
2. Запустите двойным кликом `run.bat`.
3. При первом запуске появится окно настроек — вставьте ссылку на свой
   Steam-профиль и нажмите «Сохранить».

## Сборка одного .exe файла (чтобы Python не требовался)

1. Установите Python (см. выше) — он нужен только для самой сборки.
2. Запустите двойным кликом `build.bat`.
3. Дождитесь окончания (скачаются зависимости, соберётся exe).
4. Готовый файл появится здесь: `dist\SteamHoursViewer.exe`.
   Его можно скопировать куда угодно и запускать без Python и без интернета
   (кроме загрузки данных из Steam).

## Где хранятся данные

Все файлы приложения (настройки, кэш игр, ваши изменённые значения часов)
хранятся локально в:

```
%APPDATA%\SteamHoursViewer\
├── config.json        # профиль и (если указан) API-ключ
├── overrides.json      # ваши "визуальные" переопределения часов
└── games_cache.json    # последняя успешно загруженная копия данных
```

Чтобы полностью сбросить программу — просто удалите эту папку.

## Частые проблемы

- **«Steam отдал HTML-страницу вместо XML» / ошибка разбора XML** — это
  нестабильность устаревшего публичного XML API Steam (не ваша ошибка и не
  настройки приватности). Решение: «Настройки профиля» → вставить свой
  Steam Web API ключ.
- **«Профиль приватный»** — зайдите в Steam → Ваш профиль → Изменить профиль →
  Настройки приватности → «Сведения об игре» поставьте «Открыто», либо
  укажите API-ключ в настройках программы.
- **«Профиль не найден»** — проверьте правильность ссылки/SteamID64
  (SteamID64 — это 17-значное число).
- **Антивирус ругается на .exe, собранный PyInstaller** — это известная
  особенность PyInstaller (ложное срабатывание), т.к. он упаковывает
  Python в один файл. Можно запускать через `run.bat` вместо .exe, либо
  добавить файл в исключения антивируса.
