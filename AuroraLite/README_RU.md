# AuroraLite — шейдеры для Minecraft 1.16.5

Лёгкий shader pack для Minecraft Forge 1.16.5. Forge сам по себе шейдеры не загружает, поэтому нужен один из загрузчиков:

- **OptiFine 1.16.5 HD U G8** или новее;
- **Iris + Sodium** с совместимостью для 1.16.5.

## Установка

1. Установи Forge 1.16.5.
2. Добавь OptiFine 1.16.5 в папку `mods` (либо Iris, если используешь его сборку).
3. Скопируй `AuroraLite.zip` в `.minecraft/shaderpacks`.
4. Открой `Настройки → Настройки графики → Шейдеры` и выбери `AuroraLite`.

Для Windows папка обычно находится по адресу `%APPDATA%/.minecraft/shaderpacks`.

## Что внутри

- мягкий дневной свет и тёплый оттенок на закате;
- более холодная и приглушённая картинка во время дождя;
- простая анимация воды;
- лёгкая виньетка и тональная компрессия;
- отдельный проход для руки, блоков, воды и неба;
- GLSL 1.20 для совместимости с OptiFine 1.16.5.

Это базовая производительная версия без тяжёлых SSAO, volumetric lighting и настоящего bloom. На слабом компьютере отключи сглаживание в настройках OptiFine и поставь 8–12 чанков.

## Важно

Пакет рассчитан на стандартные ресурсы Minecraft 1.16.5. С ресурспаками с нестандартными форматами света возможны отличия в цвете. Если игра показывает `Invalid program`, посмотри `latest.log`: чаще всего причина в старой версии OptiFine или в конфликтующем shader pack.
