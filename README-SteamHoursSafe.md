# Steam Hours Safe

Безопаснее переписанный офлайн-редактор локального `localconfig.vdf` для Windows.

## Отличия от исходной SteamHours V2

- не требует и не запрашивает права администратора;
- не отключает интернет;
- не завершает Steam или службы;
- не выполняет команды через shell;
- не делает сетевых запросов и не содержит сторонних Python-зависимостей;
- отказывается изменять файл, пока `steam.exe` запущен;
- разрешает запись только в ожидаемый `userdata/<SteamID>/config/localconfig.vdf`;
- перед каждой записью создаёт отдельную резервную копию;
- записывает через временный файл и атомарную замену;
- после записи проверяет байты;
- просит подтверждение перед изменением.

> Программа меняет только локальное представление данных. Steam может перезаписать файл. Используйте на свой риск и не пытайтесь обходить правила Steam.

## Запуск исходника

Требуется Python 3.11+ с Tkinter:

```powershell
python steam_hours_safe.py
```

## Проверка

```powershell
python -m unittest -v
```

## Сборка EXE

Windows EXE собирается прозрачным GitHub Actions workflow из конкретного коммита. Команда эквивалентной локальной сборки:

```powershell
python -m pip install pyinstaller==6.16.0
pyinstaller --noconfirm --clean --onefile --windowed --name SteamHoursSafe steam_hours_safe.py
```

После сборки обязательно проверьте SHA-256 опубликованного файла. Неподписанный EXE может вызвать предупреждение SmartScreen; это не заменяет цифровую подпись издателя.
